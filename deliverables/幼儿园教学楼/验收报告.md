## 与任务建议量的差异（必须知悉）

1. **1F 配电间净面积 6.3 m²**，低于任务建议“约 9 m²”；1F 电梯厅 5.2 m²。6–7 轴被楼梯间 2、电梯井、电梯厅与配电间共同挤占。  
2. **1F 的 M8 货运门**位于 B6 轴北侧服务面，服务厨房/备餐/库房，但没有独立室外北货运入口；总平面货运流线未落实。  
3. **1F 配电间名称字高取 300 mm**（任务建议房间名 350 mm）：该房间净宽仅 1.2 m，350 mm 字高会穿墙；其余房间名为 350 mm、面积 250 mm。  
4. **标准层门窗实际数量**：M2×3、M3×9、M4×9、M5×4、M6×2、M7×1、C1×6、C2×3、C3×11、C4×4、共 52 樘/层。任务建议清单为 M3×6、M4×7、C3×6；多出的 M3/M4 用于北区专用活动室、办公、教研室、公共卫生间、电梯厅与配电间，多出的 C3 用于北区各室采光。  
5. **标准层 C4 高窗**有 1 樘落在 B 轴走廊侧（卫生间高窗），不是全部朝室外；这是内部服务带布局造成的方案折衷。  
6. **构件块名为带 ID 后缀**（`AA_WALL_<id>`、`AA_OPENING_<id>`、`AA_ROOM_<id>`、`AA_AXGRID_<id>`），按 `AA_` 前缀验收；任务文字的基名未逐字一致。  
7. **额外图层**：`AA-STAIR`、`AA-TABLE`、`AA-TITLE` 不在任务给出的 10 个图层清单中，但均满足 `AA-` 前缀；第 8 条按前缀判定通过。  
8. **非等距轴网**：X 轴 1–7 等距 8400（总 50400），Y 轴 A–B 9600、B–C 3000、C–D 6600（总 19200）；回读 X/Y 偏差均为 0.000 mm。  
9. **合规声明**已写入每层说明：按 JGJ 39-2016 幼儿园层数不宜超过 3 层；本图为 5 层假设性方案，层数与消防需专项论证；本报告不声称符合该规范层数要求。  
10. **3F–5F 构件 ID**：复制时块名、`AA_ID`、`AA_WALLID`、`AA_WALLS` 引用统一改为 F3/F4/F5；2F 模板保持 F2 不变。门窗编号在房间文字落图后执行一次自动避让，`audit` 的 `opening_text_overlap` 为 0。

## 复现

```
python build_kindergarten.py 1        # 一层
python build_kindergarten.py 2        # 二层标准层模板
python clone_standard.py 3 4 5        # 三/四/五层复制标准层

```
