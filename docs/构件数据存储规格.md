
## 33 楼层复制 / 标准层（v1.0.34，B7 第三项）

### 33.1 为什么是"复制"而不是"阵列"

学校、宿舍、办公楼这类多层工程，二~N 层平面往往与"标准层"几乎一样：差几道隔墙、差一个
设备平台。人工再画一遍既慢又容易漏门窗。天正的做法是"标准层/层间复制"：选源层构件、给目标
层号、可选平移，生成后仍可逐件改。我们照这个口径做 `copy_floor`，**一次调用生成一整层**，
不做参数化阵列（阵列一旦改源层不会联动，反而更难维护）。

### 33.2 规则

- 只复制**带 `AA_FLOOR` 属性**的构件：墙、墙上的门窗、房间；
- 楼梯 / 柱 / 台阶 / 散水目前**没有层号属性**，不复制（否则会跨层乱跑）。要复制它们，先给这些
  构件补 `AA_FLOOR`，再扩 `copy_floor`，文档与测试同步改；
- 门窗、房间的编号统一加前缀（`2W001` / `2M001` / `2R001`），宿主墙编号同步换到新墙；
- 房间围合墙全部换成新层墙号，**面积必须与源层一致**（不等就报错，说明围合关系错了）；
- `offset` 只做整体平移（`(0, 9000)` 把整层挪到上方 9m，便于同图并排核对），不改变构件尺寸。

### 33.3 校验（六类拒绝）

| 情况 | 报错关键词 |
|---|---|
| 源层与目标层相同，或任一 <1 | 相同 |
| 源层没有任何墙 | 没有墙 |
| 目标层已有墙（避免叠图） | 已有墙 |
| 新墙编号与图上已有构件冲突 | 冲突（提示给 `prefix`） |
| `offset` 不是两个数 | 偏移 |

### 33.4 返回字段

`{ok, src, dst, offset, walls, openings, rooms, counts{walls,openings,rooms}, skipped_openings, skipped_rooms}`；
编号列表按图元顺序返回（调用方断言请先排序）。`skipped_*` 说明"为什么没带过来"（如"宿主墙不在源层"
"围合墙不在源层"），不静默丢构件。

### 33.5 接口

- 库：`copy_floor(session, src_floor, dst_floor, offset=(0,0), prefix="")`；
- CLI：`copy-floor <dxf> --from 1 --to 2 [--offset 0,9000] [--prefix 2]`（原地改图，回 JSON）；
- MCP：`aa_copy_floor`（`path/from/to/offset/prefix`，工具数 45，`SERVER_INFO` 1.0.34）。

### 33.6 未做

楼梯/柱/台阶/散水的层号与复制；跨图幅复制（把标准层复制到另一张图框里，现在只能同图平移）；
"标准层"概念（一次复制到 2..N 层，需要循环调用）；复制后自动补楼层表行（现需 `floors` 手工登记）。

### 33.7 验收（test_floor_copy）

一层 7200×4500 四墙 + 一门一窗一房间 → 复制到 2 层（offset `(0,9000)`、prefix `2`）：4 墙 2 门窗
1 房间，墙/门窗/房间编号均带 `2`，房间面积 21657600 mm² 与源层一致，围合墙换成 `2W00x`；
重复复制到 2 层被"已有墙"拒绝；1→3 再复制成功；五类非法参数各自拒绝；CLI `copy-floor` 与库一致。
样例 `tools/demo_floor_copy.py`：一层平面 + 整层复制出的二层平面（同图上下并排，窗/门/房间标注一致）。
