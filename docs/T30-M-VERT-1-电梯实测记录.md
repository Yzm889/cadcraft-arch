## 2. 命令入口与前置条件

### 2.1 入口

| 入口 | 实测 |

| 命令行 | `TElevator`（命令日志原文：`命令: TElevator`） |
| 菜单/工具栏 | 未单独验证；面板入口已确认可用 |

### 2.2 前置条件（实测）

1. **必须已有闭合井道**：命令前后 `TDbWall` 数量均为 71，未新建墙；命令只画电梯符号与门洞。
2. **井道两个角点必须是墙内表面角点**，不是墙中心线：
   - 用墙中心线 `375,27525` / `3200,29900` 时，第二点被拒，命令重新提示"再给出上一角点的对角点"。
   - 改用内表面角点 `500,27650` / `3075,29775` 后通过。
3. **开门墙线必须点在墙内表面线上**：
   - `1787.5,27525`（中心线）被拒，重新提示"请点取开电梯门的墙线"。
   - `1787.5,27650`（南墙内表面）通过。
4. **必须指定平衡块所在侧**：`1787.5,29775`（北侧）通过。
5. **其他开门墙线可空**：提示 `<无>`，默认无；按回车后命令回到起点，可继续插入下一台。

### 3.2 命令行提示序列（完整）

```text
TElevator
请给出电梯间的一个角点或 [参考点(R)]<退出>:
再给出上一角点的对角点:
请点取开电梯门的墙线<退出>:
请点取平衡块的所在的一侧<退出>:
请点取其他开电梯门的墙线<无>:
（回到）请给出电梯间的一个角点或 [参考点(R)]<退出>:
```

- 输入顺序固定为：角点 → 对角点 → 开门墙线 → 平衡块侧 → 其他开门墙线（可空）。
- 成功后**不退出命令**，回到第一个提示，可连续插入；需 Esc 退出（本轮通过关闭进程结束）。
- 全程未出现电梯编号/层号/插入基点/旋转角提示。

## 4. 四向门与块旋转

### 4.2 块旋转

- **没有电梯块参照**：`AcDbBlockReference` 数量为 0；电梯符号是 10 条直接落在模型空间的 `AcDbLine`。
- 因此**没有块旋转角**可记录；门朝向由所点墙线决定，不是靠块旋转。
- 新增块定义 `$DORLIB2D$00000127`（9 条 `AcDbPolyline`），但模型空间无对应块参照；属门库内部定义，未观察到旋转。

## 6. 失败与重复执行

| 场景 | 实测行为 |
|---|---|
| 空白区域（无井道墙）建电梯 | 两点+门墙点被接受后命令静默结束，**未生成电梯实体**；仅新建 `EVTR` 图层。DXF 只多图层，无实体。 |

| 重复编号/重叠井道 | **UNKNOWN**：未测试；命令无编号输入，重复插入行为未验证。 |

## 7. 对现有规格的修正

### 7.1 已确认

- 电梯命令需要**已有闭合井道墙**；命令不创建井道墙（`TDbWall` 数量不变）。
- 默认轿厢 1600×1400、门宽 1100、门高 2100；与 `spec` 的默认值一致。
- 门洞是真实洞口（公共 `Width/Height` 可读），不是纯符号。
- 开门墙线、井道角点都必须取**墙内表面**，不是中心线。
- 必须指定平衡块所在侧；平衡块会画出来。
- 命令循环插入，不是单次即退。

### 7.2 需修改（与现 spec 不一致）

| 项 | 现 spec | T30 实测 | 建议修正 |
|---|---|---|---|
| 块内图元 | 7 LINE + 1 TEXT | **10 LINE + 0 TEXT**；无块参照，直接模型空间线 | 改为 10 LINE；删除"电梯"文字；若要块，需明确是自研选择 |
| 对重 | 首期删除（按需求范围） | 实际绘制对重 1287.5×181.3，位于指定侧 | 增加 `cw_side` 参数与对重矩形（或明确列为可选） |
| 图层 | 复用 `AA-STAIR`/`AA-STAIR-TEXT` | 专用 `EVTR`（黄 2） | 待拍板：新增 `AA-ELEV` 还是复用 |
| 门洞 | 复用 `opening`，编号 `<id>-D` | 真实 `TDbOpening`，`Width=1100/Height=2100`，图层 `WINDOW`；无编号提示 | 保留复用 `opening` 方案；明确门洞图层/编号策略 |
| 其他门 | 未定义 | 命令有"其他开电梯门的墙线<无>"循环提示 | 增加 `extra_doors` 参数（默认空） |
| 轿厢定位 | 居中 | 向门侧偏移约 181.2，给对重留空间 | 增加 `car_offset` 规则（具体公式 UNKNOWN） |
| 失败行为 | 零改动 | 失败留 `EVTR` 图层，几何零残留 | 保持"零改动"更严；文档注明差异 |
| 命令循环 | 未定义 | 成功后循环插入，需 Esc 退出 | CADCraft 版建议单次插入，由调用方重复 |

## 9. 待你拍板（已于 2026-11-24 拍板，定稿见 spec §13）

1. **图层**：
   - A. 复用 `AA-STAIR`/`AA-STAIR-TEXT`（低回归，但电梯与楼梯同色/同层）；
   - B. 新增 `AA-ELEV`（颜色 2，接近 T30 的 `EVTR`；需改 21 层注册表、`layers` 命令与测试）。
2. **门洞编号**：
   - A. 复用 `opening` 自动编号（如 `M1100`）；
   - B. 电梯门单独编号/不编号（需给 `opening` 加 `--no-label` 或专用字段）。
3. **对重**：
   - A. 纳入 M-VERT-1（T30 实测会画，1287.5×181.3）；
   - B. 按原范围不做（与实测不一致，但保持首期小）。
4. **命令循环**：
   - A. CADCraft 版单次插入、由调用方重复（推荐，便于 CLI/幂等）；
   - B. 照 T30 循环插入（交互式，但 CLI 不好用）。
5. **失败时图层**：
   - A. 保持零改动（推荐）；
   - B. 允许像 T30 一样留下 `EVTR` 层（不建议）。
6. **坡道/阳台约定**（C2/C3 再定）：箭头方向、`i=1:n` 注字、栏杆默认是否绘制。
