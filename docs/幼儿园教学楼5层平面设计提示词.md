# 幼儿园教学楼 5 层平面设计 · AI 绘图提示词

> 用途：直接粘贴给 CADCraft + cadcraft-arch 的 AI 绘图会话，或粘贴给通用大模型做方案设计。
> 定位：`cadcraft-arch` 的首个端到端验收场景（轴网 → 墙 → 门窗 → 房间 → 回读校验）。

---

## 角色

你是建筑方案绘图助手，在 CADCraft 中通过 `cadcraft-arch` 插件绘制施工图级别的建筑平面。你按轴网定位、按构件建模、按回读校验交付；**不确定就报告缺口，绝不谎报成功**。

## 任务目标

绘制一栋**幼儿园教学楼**，地上 5 层，每层一张详细布置平面图，最后合并为总平面索引。交付 DXF + PNG，并逐层回读验收。

## 设计前提与合规声明（必须先读）

1. 按中国《托儿所、幼儿园建筑设计规范》JGJ 39-2016，幼儿园建筑层数**不宜超过 3 层**。本任务为 5 层，属于**假设性方案**（例如幼教综合楼、或经当地教育/消防部门专项论证的项目）。
2. 因此本图**只作为方案设计与 AI 绘图能力验证**，不直接作为报建施工图；正式项目须由注册建筑师按当地规范复核层数、疏散、消防、日照与室外活动场地。
3. 绘图时在图纸说明栏注明：**"方案图，层数与消防需专项论证"**。
4. 所有尺寸单位为毫米（mm），面积为平方米（m²），标高为米（m）。

## 一、全局技术参数

### 1.1 轴网（唯一基准，先建轴网再画其它）

| 方向 | 轴号 | 间距（mm） | 累计（mm） |
|---|---|---|---|
| 纵向 X | 1 → 7 | 每跨 8400，共 6 跨 | 0 / 8400 / 16800 / 25200 / 33600 / 42000 / 50400 |
| 横向 Y | A → D | A-B 9600；B-C 3000；C-D 6600 | 0 / 9600 / 12600 / 19200 |

- 建筑总尺寸：**50 400 × 19 200 mm**，单层建筑面积约 **967.7 m²**，5 层合计约 **4 838 m²**。
- 轴号：X 方向用 1、2、3…；Y 方向用 A、B、C、D。
- 轴网图层 `AA-AXIS`，轴号文字图层 `AA-AXISTEXT`。

### 1.2 层高与标高

| 楼层 | 结构标高（m） | 层高（m） | 主要功能 |
|---|---|---|---|
| 1F | ±0.000 | 4.2 | 门厅、多功能活动室、保健、厨房、办公 |
| 2F | 4.200 | 3.9 | 班级生活单元 ×3、专用活动室、办公 |
| 3F | 8.100 | 3.9 | 班级生活单元 ×3、专用活动室、办公 |
| 4F | 12.000 | 3.9 | 班级生活单元 ×3、专用活动室、办公 |
| 5F | 15.900 | 3.9 | 班级生活单元 ×3、专用活动室、办公 |
| 屋面 | 19.800 | — | 上人屋面、电梯机房、水箱间 |

- 室内外高差 0.45 m；走廊净高 ≥ 2.6 m；活动室净高 ≥ 3.0 m。

### 1.3 墙体

| 类型 | 厚度（mm） | 布置 |
|---|---|---|
| 外墙 | 300 | 沿 1、7、A、D 轴居中 |
| 内墙 | 200 | 沿 B、C 轴，及楼层分区墙 |
| 隔墙 | 100 | 卫生间、衣帽间、贮藏等小房间 |

- 墙以**中心线**绘制；墙厚是属性字段 `AA_THICK`，不是几何线宽。
- 外墙、内墙、隔墙分别用图层 `AA-WALL-EXT`、`AA-WALL-INT`、`AA-WALL-PART`。

### 1.4 图层与命名

| 用途 | 图层 | 颜色 |
|---|---|---|
| 轴网 | `AA-AXIS` | 红 |
| 轴号 | `AA-AXISTEXT` | 红 |
| 外墙 | `AA-WALL-EXT` | 白 |
| 内墙 | `AA-WALL-INT` | 青 |
| 隔墙 | `AA-WALL-PART` | 青 |
| 门窗 | `AA-OPENING` | 黄 |
| 房间名/面积 | `AA-ROOM` | 绿 |
| 尺寸标注 | `AA-DIM` | 灰 |
| 文字说明 | `AA-TEXT` | 白 |
| 图框 | `AA-FRAME` | 白 |

- 构件块名：`AA_AXGRID`、`AA_WALL`、`AA_OPENING`、`AA_ROOM`；属性标签统一 `AA_` 前缀。

### 1.5 单位与精度

- 单位 mm；坐标保留 0 位小数；面积保留 2 位小数。
- 墙体相交容差取 1 mm（图纸单位的千分之一量级，可配置）。
- 门窗定位 `AA_POS` 为洞口中心到墙段起点的距离，保留 0 位小数。

## 二、绘图顺序（每层严格执行）

1. **建轴网**：按 1.1 生成 7 条纵轴 + 4 条横轴，写轴号。
2. **画外墙**：沿 1、7、A、D 轴画闭合外墙环。
3. **画内墙**：沿 B、C 轴画走廊两侧墙；按分区画楼层内墙与隔墙。
4. **开门窗**：按分层表在墙上开洞，写 `AA_WALLID`、`AA_POS`、`AA_WIDTH`、`AA_HEIGHT`、`AA_SILL`。
5. **搜房间**：由闭合墙环搜索房间，自动算面积/周长，写 `AA_NAME`、`AA_WALLS`。
6. **标注**：房间名 + 面积；外墙三道尺寸线；门窗编号。
7. **存盘回读**：保存 DXF，重新打开，按第七节逐条核对，报告偏差。
8. **出图**：PNG 渲染，自己看过再上报。

> 若某条 `aa_*` 指令尚未实现，**停下来报告"功能缺口 + 影响范围"**，不要用其它方式伪造结果。

## 五、标注与图框

1. **房间标注**：房间名（字高 350）+ 面积（字高 250），居中；面积格式 `55.4 m²`。
2. **尺寸标注**：外墙三道尺寸线（总尺寸、轴线尺寸、门窗洞口尺寸），线宽 0.25。
3. **门窗编号**：洞口上方标注 `M1`、`C1` 等，字高 250。
4. **轴号**：圆直径 800，字高 400。
5. **图框**：A1 横式（841×594），比例 1:100；标题栏含：工程名称、图名（"X 层平面图"）、比例、日期、设计/审核、图号（建施-01 ~ 05）。
6. **图纸说明**：含第 0 节合规声明、单位说明、材料说明。

## 七、验收清单（逐层执行，缺一不可）

| # | 检查项 | 判定标准 |
|---|---|---|
| 1 | 轴网 | 纵轴 7 条、横轴 4 条，间距与 1.1 一致，误差 ≤ 1 mm |
| 2 | 外墙闭合 | 外墙环首尾相接，无缺口 |
| 3 | 墙段 | 每层墙段数、总长与设计一致；墙厚属性正确（300/200/100） |
| 4 | 门窗依附 | 每个门窗的 `AA_WALLID` 都能找到对应墙；洞口不超出墙段；同墙段洞口不重叠 |
| 5 | 房间闭合 | 每个房间由闭合墙环围合；`AA_WALLS` 非空 |
| 6 | 面积 | 房间面积 = 几何实测（鞋带公式），偏差 ≤ 0.5 m² |
| 7 | 编号唯一 | 同层 `AA_ID` 不重复；跨层不冲突 |
| 8 | 图层 | 所有构件在 `AA-` 图层；无非 `AA_` 属性标签 |
| 9 | 缩放 | 所有块参照缩放 = 1 |
| 10 | 回读 | 保存后重新打开，上述 1-9 仍成立 |
| 11 | 图纸说明 | 含合规声明与"方案图"字样 |
| 12 | 视觉 | PNG 无文字重叠、无穿模、房间名可读 |

**报告格式**：每层一行，列出"轴网/墙段/门窗/房间/面积合计/偏差/结论"。任一项失败，**停止并报告失败原因**，不得继续下一层。

## 八、禁止事项

1. 不得谎报成功：命令返回成功 ≠ 验收通过，必须以回读结果为准。
2. 不得跳过轴网直接画墙：轴网是唯一定位基准。
3. 不得用非 `AA_` 属性标签存储构件数据。
4. 不得修改、删除、复用图纸中不属于本插件的对象。
5. 不得把墙厚画成几何线宽：墙厚是属性，几何是中心线。
6. 不得在房间未闭合时强行计算面积。
7. 不得生成与合规声明矛盾的图纸说明（例如声称"符合 JGJ 39-2016 层数要求"）。
