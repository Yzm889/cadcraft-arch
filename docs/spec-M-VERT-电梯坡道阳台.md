## 1. 目标与非目标

### 1.1 目标

| 阶段 | 构件 | 交付 |
|---|---|---|
| M-VERT-1 | 电梯（平面符号） | 井道校验、轿厢、层门、门洞（真实开洞）、编号、图层/属性、边界/回滚/幂等 |
| M-VERT-2 | 坡道 | 坡度、长度、宽度、栏杆、方向箭头、`i=1:n` 注字、边界 |
| M-VERT-3 | 阳台（平面） | 挑出轮廓、栏板线、与外墙/洞口避让、边界 |

### 1.2 非目标

- 不做电梯三维、不做电梯选型/荷载/机房。
- 不做坡道结构、防滑、排水计算。
- 不做阳台结构配筋、排水、栏杆节点。
- 不修改现有 `wall`/`opening`/`room` 的算法；只在它们之上调用。
- 不新增图层（首期复用现有 21 层，理由见 §2.3）。

## 2. 总体设计

### 2.1 构件族与编号

| 构件 | 块名 | `AA_TYPE` | 默认编号 | 编号规则 |
|---|---|---|---|---|
| 电梯 | `AA_ELEVATOR_<ID>` | `ELEVATOR` | `EL001` | 用户可给；缺省按 `EL%03d` 找最小空号 |
| 坡道 | `AA_RAMP_<ID>` | `RAMP` | `RP001` | 同上，前缀 `RP` |
| 阳台 | `AA_BALCONY_<ID>` | `BALCONY` | `BA001` | 同上，前缀 `BA` |

- 编号在图纸内唯一；同块名重复直接拒绝（沿用现有 `create_column/create_stair` 的"已存在"语义）。
- 所有构件写入 `AA_FLOOR`（默认 1），为后续 `copy-floor` 预留；首期不改 `copy-floor`。

### 2.2 数据模型

沿用现有模式：**一个构件 = 一个块参照 + 一组不可见 `AA_` 属性**；几何在块定义内，插入缩放恒为 1。
- 写入后必须 `expect_attributes` 回读；失败即回滚。
- 回读接口：`show`（列出全部构件）、`block_geometry`（块内图元）、`attributes`（属性）。

### 2.3 图层策略（首期不新增图层）

| 构件 | 几何层 | 文字层 | 理由 |
|---|---|---|---|
| 电梯 | `AA-STAIR`（黄 2 / 0.18） | `AA-STAIR-TEXT`（白 7 / 0.18） | 电梯属竖向交通，复用楼梯色；避免改 21 层注册表与图层测试 |
| 坡道 | `AA-STEP`（白 7 / 0.18） | `AA-STAIR-ARROW`（绿 3）箭头、`AA-STAIR-TEXT` 注字 | 坡道属室外/竖向过渡，复用台阶色 |
| 阳台 | `AA-STEP`（白 7 / 0.18） | `AA-STAIR-TEXT`（可选标签） | 阳台挑板属室外构件 |

> 备选：新增 `AA-ELEVATOR` / `AA-RAMP` / `AA-BALCONY` 三组层。首期不采用——用户明确要求"回归风险比 M-OPEN 小"，新增层会牵动 `DEFAULT_LAYERS`、`ensure_layers`、`layers` 命令、21 层断言与 `aa_layers.json`。等 M-VERT 三项稳定后，如 `audit` 需要语义区分再单独立项。

### 2.4 比例与字高

- 字高统一走现有 `annot_size(mm, scale)`：默认 2.5mm@1:100 → 250 图纸单位。
- 几何是真实尺寸，不随出图比例缩放（与柱/楼梯一致）。

### 2.5 回读、回滚、幂等总则

- **先全量校验，后写图**；任何校验失败 → 抛 `CadError`，图纸零改动。
- 写图前整图字节快照；写图异常 → 原子回写，不依赖 `.bak` 能否存活。
- 同编号重复执行 → 拒绝"已存在"，图纸字节不变（幂等 = 不产生重复/半成品，不是静默成功）。
- 每个构件写完立即 `expect_attributes` + `block_geometry` 断言；任一失败即回滚。

## 3. M-VERT-1 电梯（详细规格）

> **T30 实测修正（2026-11-24）**：电梯图元实际为 **10 条 LINE + 0 条 TEXT**（轿厢 4 + 对角线 2 + 对重 4），无块参照；专用图层 `EVTR`（黄 2）；门为真实 `TDbOpening`（宽 1100 / 高 2100，图层 `WINDOW`）；命令要求已有闭合井道墙，且角点/门墙点都取墙**内表面**。详见 §12、§13 与 `docs/T30-M-VERT-1-电梯实测记录.md`；以下 §3 的参数与图元清单**以 §13 定稿为准**。

### 3.1 目标

在建筑平面图上画一个**电梯平面符号**：井道（由已有墙围合，校验）、轿厢、层门、门洞（复用 `opening` 真实开洞）、编号与属性；失败零残留。

### 3.2 前置状态

1. 图纸已 `new`（21 标准层已建），或至少 `AA-STAIR`/`AA-STAIR-TEXT`/`AA-OPENING` 层存在（绘制前会自动补建）。
2. 井道四壁已用 `wall` 画好，形成闭合矩形；四堵墙的编号已知（`--shaft-walls` 必填，首期不做自动搜索）。
3. 门所在墙的墙段长度足够放下门洞，且该墙上没有与门洞重叠的已有洞口。
4. 电梯编号未被占用。

### 3.3 输入参数与默认值

| 参数 | 类型 | 默认 | 说明/校验 |
|---|---|---|---|
| `id` | 字符串 | `EL001` | 缺省自动取最小空号；重复拒绝 |
| `at` | [x,y] | 必填 | 井道**净空中心**（世界坐标） |
| `shaft` | [w,d] | `[2200,2200]` | 井道**净**宽×净深（内表面之间） |
| `car` | [w,d] | `[1600,1400]` | 轿厢净尺寸；须 `car_w+2×gap ≤ shaft_w`、`car_d+2×gap ≤ shaft_d` |
| `door` | 实数 | `1100` | 层门洞口宽；700–1600 |
| `door_h` | 实数 | `2100` | 门洞高，写 `AA_HEIGHT` |
| `door_side` | `N/E/S/W` | `S` | 门在井道的哪一侧 |
| `shaft_walls` | 4 个墙号 | 必填 | 顺序：`N,E,S,W`（北/东/南/西），允许任意顺序但须能围成矩形 |
| `gap` | 实数 | `100` | 轿厢与井道内表面的最小净距；≥0 |
| `label` | 字符串 | `电梯` | 轿厢中心注字；空串表示不注字 |
| `angle` | 实数 | 0 | 块旋转角（度）；首期仅允许 0/90/180/270 |

### 3.4 平面几何构造（块本地坐标）

块本地：原点 = 井道净空中心；`+X` 东、`+Y` 北；门在 `+Y`（北）侧。插入时按 `door_side` 旋转：

| `door_side` | 插入旋转（度） |
|---|---|
| N | 0 |
| E | -90（或 270） |
| S | 180 |
| W | 90 |

图元（块内，共 **7 条 LINE + 1 条 TEXT**）：

| # | 图元 | 坐标/尺寸 | 层 |
|---|---|---|---|
| 1–4 | 轿厢矩形 | 中心 (0,0)，`car_w × car_d` | `AA-STAIR` |
| 5 | 层门左扇 | `(-door/2, shaft_d/2 - 60)` → `(0, shaft_d/2 - 60)` | `AA-STAIR` |
| 6 | 层门右扇 | `(0, shaft_d/2 - 60)` → `(door/2, shaft_d/2 - 60)` | `AA-STAIR` |
| 7 | 门洞门槛线 | `(-door/2, shaft_d/2)` → `(door/2, shaft_d/2)` | `AA-STAIR` |
| 8 | 注字 `label` | 插入点 (0,0)，字高 `annot_size(2.5)` | `AA-STAIR-TEXT` |

> 井道轮廓**不画**：由已有四堵墙表达，避免与墙线重复；`AA-WALL` 不变。

门洞真实开洞：
- 复用 `create_opening`，`kind=DOOR`，`width=door`，`height=door_h`，`sill=0`，`label_side="in"`；
- 门洞编号 `"<id>-D"`（如 `EL001-D`），所在墙 = `door_side` 对应的那堵墙；
- 门洞中心沿墙位置 `door_pos` 默认 = 该墙段中点；可由用户覆盖；
- 开洞会重建所属墙块（墙侧线断开），这是预期行为。

### 3.5 生成/修改实体

| 项 | 规格 |
|---|---|
| 新增 | `INSERT AA_ELEVATOR_<ID>`（块内 7 LINE + 1 TEXT） |
| 新增 | `INSERT AA_OPENING_<ID>-D`（层门洞口，`AA_TYPE=OPENING`） |
| 修改 | 门所在墙块重建（洞口区间断线） |
| 图层 | 电梯几何 `AA-STAIR`、注字 `AA-STAIR-TEXT`、门洞 `AA-OPENING` |
| 属性 | 见下表 |
| 不修改 | 其它墙、房间、尺寸、图框、图纸集 |

电梯属性（全部不可见，`AA_` 前缀）：

| 属性 | 值 |
|---|---|
| `AA_TYPE` | `ELEVATOR` |
| `AA_ID` | `EL001` |
| `AA_W` / `AA_D` | 井道净宽 / 净深 |
| `AA_CAR_W` / `AA_CAR_D` | 轿厢宽 / 深 |
| `AA_DOOR` / `AA_HEIGHT` | 门宽 / 门高 |
| `AA_DOOR_SIDE` | `N/E/S/W` |
| `AA_DOOR_WALL` | 门所在墙号 |
| `AA_POS` | 门洞中心沿墙位置 |
| `AA_GAP` | 净距 |
| `AA_ANGLE` | 插入旋转（度） |
| `AA_ATX` / `AA_ATY` | 井道净空中心 |
| `AA_LABEL` | 注字 |
| `AA_FLOOR` | 层号（默认 1） |

### 3.6 操作步骤

1. 校验编号未占用、`shaft/car/door/gap` 数值合法、`door_side` 合法、`angle` 合法。
2. 读取 4 堵 `shaft_walls` 的几何与厚度，判定每堵墙的"朝井道内表面"；四内表面必须围成 `shaft_w × shaft_d` 的矩形（容差 1mm），否则拒绝并报告哪一面偏了多少。
3. 校验门所在墙 = `door_side` 对应墙；计算 `door_pos` 默认值（该墙中点）；用 `create_opening` 的规则预检门洞是否越界/重叠（不写图）。
4. 生成电梯块：`aa:elevator` LISP 画 11 线 + 1 字 → `make_block` → `insert`（旋转按 §3.4）。
5. 创建门洞：调用 `create_opening`（真实断墙）。
6. 回读：`expect_attributes`、`block_geometry` 计数、门洞块存在、门墙开洞区间；任一项失败 → 回滚（删除本次新增的电梯块与门洞块，恢复墙块/整图字节快照）。
7. 返回结构化结果：`block/handle/opening/opening_handle/wall/door_side/door_pos/geom_handles`。

### 3.7 边界、异常、回滚、幂等

| 场景 | 处理 |
|---|---|
| 编号已存在 | 拒绝："电梯 EL001 已存在，请换编号"；零改动 |
| 4 堵井道墙缺失/数量≠4 | 拒绝；零改动 |
| 四墙未闭合 / 内表面尺寸与 `shaft` 差 >1mm | 拒绝，报告偏差面与偏差值；零改动 |
| `door_side` 对应的墙不在 `shaft_walls` 里 | 拒绝 |
| 门宽 <700 或 >1600 | 拒绝 |
| 门洞越出墙段 / 与已有洞口重叠 | 由 `create_opening` 拒绝；电梯块不落地（先校验后写） |
| 轿厢放不进井道（含 `gap`） | 拒绝，报告可用净尺寸 |
| `gap<0`、`shaft<=0`、`car<=0`、`angle∉{0,90,180,270}` | 拒绝 |
| 写图过程中 LISP/块/属性失败 | 整图字节快照回写；不留下电梯块、门洞块或断墙 |
| 同一条命令重复执行 | 第二次因"已存在"拒绝；图纸字节不变 |
| 门洞创建成功但电梯块失败 | 回滚门洞（恢复墙块）与电梯块；零残留 |

## 4. M-VERT-2 坡道（规格）

### 4.1 目标

在平面图上画坡道：两条边线 + 端线 + 方向箭头 + `i=1:n` 注字；可选扶手线；真实尺寸，不随比例缩放。

### 4.2 前置

- 起点/终点已定；坡道长度 ≥ 1000；宽度 ≥ 900（无障碍建议 ≥1200）。
- 坡度 `n`（1:n）在 8–20 之间；`n<12` 时返回 warning（陡于无障碍 1:12），不拒绝。

### 4.3 参数与默认值

| 参数 | 默认 | 校验 |
|---|---|---|
| `id` | `RP001` | 重复拒绝 |
| `p1,p2` | 必填 | 两点距离 = 坡道长 ≥1000 |
| `width` | 1500 | ≥900 |
| `slope` | 12 | 8–20；<12 给 warning |
| `rail` | true | 是否画两侧扶手线 |
| `arrow` | `up` | `up`/`down`，箭头指向 |
| `label` | 自动 `i=1:12` | 可覆盖；空串不注字 |

### 4.4 图元（块本地，+X 从 p1→p2）

| 图元 | 数量 | 层 |
|---|---|---|
| 两侧边线 | 2 | `AA-STEP` |
| 两端端线 | 2 | `AA-STEP` |
| 扶手线（rail=true） | 2 | `AA-STEP` |
| 箭头杆 | 1 | `AA-STAIR-ARROW` |
| 实心箭头 | 1 SOLID | `AA-STAIR-ARROW` |
| 注字 `i=1:n` | 1 TEXT | `AA-STAIR-TEXT` |

- `rail=true`：8 LINE + 1 SOLID + 1 TEXT；`rail=false`：6 LINE + 1 SOLID + 1 TEXT。
- 插入点 = `p1`，旋转 = `atan2(p2-p1)`；属性 `AA_TYPE=RAMP`、`AA_ID`、`AA_W`、`AA_LEN`、`AA_SLOPE`、`AA_ANGLE`、`AA_RAIL`、`AA_ATX/ATY`、`AA_FLOOR`。

### 4.5 边界/回滚/幂等

- 拒绝：编号重复、长度<1000、宽度<900、坡度<8 或>20、两点重合——零改动。
- warning：坡度 8–11（陡于 1:12），返回 `warnings`，不阻断。
- 同编号重复执行 → 拒绝；失败零残留；回滚同 §2.5。

### 4.6 证据/UNKNOWN

- E-T01（`TAscent`）、E-T02（`10-楼梯与其他.pdf`）。
- U-09：天正坡道箭头方向（上坡/下坡）、注字格式（`i=1:12` vs 百分比）、是否画扶手——未实测；本规格默认"箭头上坡、`i=1:n`、画扶手"，可参数覆盖。

## 5. M-VERT-3 阳台（平面，规格）

### 5.1 目标

在外墙上画平面阳台：挑出轮廓 + 栏板线；校验与外墙/洞口避让；真实尺寸。

### 5.2 前置

- 依附墙存在且为外墙（`AA_KIND=EXTERNAL` 推荐；内墙只 warning）。
- 阳台区间 `[pos-w/2, pos+w/2]` 完全落在墙段内。
- 区间内不得有已有门窗洞口（重叠即拒绝）。

### 5.3 参数与默认值

| 参数 | 默认 | 校验 |
|---|---|---|
| `id` | `BA001` | 重复拒绝 |

## 13. C1 定稿：电梯（M-VERT-1）

> 本节为 2026-11-24 拍板后的最终 C1 规格；与 §3/§12 冲突处，以本节为准。

### 13.1 拍板结果

| # | 决定 |
|---|---|
| 1 | **新增图层 `AA-ELEVATOR`**（黄 2、实线、0.18），不改 `AA-STAIR`。C1 单独提交层注册、层断言与回归。 |
| 2 | **电梯门编号 `<电梯ID>-D`**（如 `EL001-D`），不复用 `opening` 自动编号 `M1100`；普通门窗自动编号逻辑不变。`opening-table` 是否排除电梯门另开小任务，不混入 C1。 |
| 3 | **对重纳入 C1**：C1 图元为 **10 条 LINE + 0 条 TEXT**；对重尺寸按自研比例（约 `0.8×轿厢宽`、`0.13×轿厢深`）计算，不照抄 T30 的 1287.5×181.3；新增 `AA_CW_SIDE / AA_CW_W / AA_CW_D`，门侧与对重侧必须明确。 |
| 4 | **单次插入**，不照 T30 循环；重复插入由调用方显式再调用；CLI/MCP 返回本次插入结果。 |
| 5 | **失败零残留**：先全量校验，再整图字节快照；门洞或电梯块任一步失败，整图原子回滚；不允许留下空 `AA-ELEVATOR` 层。 |

### 13.2 两条边界（必须写进 C1）

1. **门向证据边界**：T30 本轮只实测**南向门**；北/东/西向只算"按旋转角推导的自研行为"，**不能写成已与天正确认**。
2. **资源边界**：T30 的 `EVTR` 图层、`$DORLIB2D$...` 门库块、精确坐标只作为行为证据，**不复制**到 CADCraft；CADCraft 使用 `AA_ELEVATOR_<ID>` 块 + `AA_` 属性 + 真实 `create_opening` 门洞。

### 13.3 最终参数

| 参数 | 类型 | 默认 | 校验/说明 |
|---|---|---|---|
| `id` | 字符串 | `EL001` | 重复拒绝 |
| `at` | [x,y] | 必填 | 井道净空中心（世界坐标） |
| `shaft` | [w,d] | `[2200,2200]` | 井道**净**宽×净深（内表面之间） |
| `car` | [w,d] | `[1600,1400]` | 轿厢净尺寸 |
| `door` | 实数 | `1100` | 门洞宽；700–1600 |
| `door_h` | 实数 | `2100` | 门洞高 |

| `cw_side` | `N/E/S/W` | **必填** | 对重所在边；C1 要求与 `door_side` **相对**（N↔S、E↔W），相邻侧留到后续 |
| `shaft_walls` | 4 个墙号 | 必填 | 顺序 `N,E,S,W`；四墙内表面须围成 `shaft × shaft` 净矩形，容差 1mm |
| `gap` | 实数 | `100` | **最小允许净距**（不是实际净距）；实际净距由几何推导，小于此值则拒绝，不偷偷缩小 |
| `cw_gap` | 实数 | `50` | 对重侧实际净距（构造值，等于对重到内表面距离） |
| `door_pos` | 实数 | 门墙中点 | 门洞中心沿门墙位置；可选覆盖 |

派生值（不手工输入）：
- `cw_w = round(0.8 × car_w)`，`cw_d = round(0.13 × car_d)`；默认轿厢 1600×1400 → 对重 **1280×182**。
- `car_offset = (cw_d + cw_gap) / 2`，轿厢沿"门侧方向"偏移，给对重让位。
- 实际门侧净距 `door_gap = shaft_d/2 - (car_offset + car_d/2)`；默认 `1100 - (116 + 700) = 284`。
- 实际对重侧净距 `cw_gap`（构造值，默认 50）。
- 校验：`door_gap ≥ gap`、两侧净距 `(shaft_w-car_w)/2 ≥ gap`、`car_d + car_offset + gap ≤ shaft_d/2`；不满足即拒绝，**不得**把 `gap` 调小。
- 块旋转：`door_side N=0 / E=-90 / S=180 / W=90`（块本地门在 +Y）。

### 13.4 最终几何（块本地坐标）

块本地：原点 = 井道净空中心；`+X` 东、`+Y` 北；门在 `+Y`，对重在 `-Y`；插入时按 `door_side` 旋转。

| # | 图元 | 规格 |
|---|---|---|
| 1–4 | 轿厢矩形 | `car_w × car_d`，中心 `(0, car_offset)`，4 条 LINE |
| 5–6 | 轿厢对角线 | 矩形两对角连线，2 条 LINE（X 形） |
| 7–10 | 对重矩形 | `cw_w × cw_d`；`y ∈ [-shaft_d/2 + cw_gap, -shaft_d/2 + cw_gap + cw_d]`，`x` 居中，4 条 LINE |

- 合计 **10 条 LINE + 0 条 TEXT**；不加"电梯"文字。
- 门洞在**世界坐标**中落到 `door_side` 对应墙：`create_opening`（`kind=DOOR`、`width=door`、`height=door_h`、`sill=0`、`no="<id>-D"`）。
- 电梯块本身不画门洞；门洞是独立 `AA_OPENING` 块，编号 `<id>-D`。

### 13.6 命令语义

- **单次插入**：成功返回本次结果（`block/handle/opening/opening_handle/attrs/geom_handles`），不循环。
- 重复插入：调用方用新 `id` 再次调用；同 `id` 再次调用 → 拒绝"已存在"，字节不变。
- CLI/MCP 参数：`elevator` / `aa_elevator`，新增 `--door-side`、`--cw-side`、`--gap`、`--cw-gap`；`--shaft-walls` 为 4 个墙号。

### 13.7 失败零残留

1. **先全量校验**：编号、数值、四墙内表面矩形、门墙、门洞越界/重叠、轿厢/对重能否放进井道；全部通过前不建层、不写图。
2. **记录层状态**：若图纸原本没有 `AA-ELEVATOR`，记录"本次将新建"；失败时删除本次新建的层。
3. **整图字节快照**：通过校验后快照；电梯块或门洞任一步失败 → 原子回写。
4. **门洞失败**：删除电梯块并恢复墙块/整图快照；不留半成品。
5. **电梯块失败**：门洞尚未创建；恢复快照；不留半成品。
6. **禁止**：失败后留下空 `AA-ELEVATOR` 层、`EVTR` 层或任何 `AA_` 半成品。
